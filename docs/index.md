# CNC Terraform Catalog (PoC)

Welkom bij de lokale PoC voor centrale Terraform module-documentatie.

## Doel
- Documentatie automatisch genereren met terraform-docs.
- Centrale site tonen met MkDocs.

## Deze PoC bevat
- 2 modules: vmnet-poc en rg-poc
- gegenereerde module-documentatie in de README van de module
